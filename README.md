# واترمارک‌زن

واترمارک زدن دسته‌جمعی روی عکس‌ها — لوگو یا متن، با یک تنظیم روی همه‌ی عکس‌ها.
**هیچ عکسی به هیچ سروری فرستاده نمی‌شود**؛ همه‌ی پردازش روی Canvas مرورگر خودت انجام می‌شود و بعد از اولین بار، کامل آفلاین کار می‌کند.

## استفاده

**آنلاین:** https://parsaaminzade.github.io/etehad-husseini/

**نصب مثل نرم‌افزار:** صفحه را باز کن و دکمه‌ی «نصب برنامه» را بزن (ویندوز، اندروید، مک).
روی آیفون: دکمه‌ی اشتراک‌گذاری ← Add to Home Screen.
بعد از نصب، یک آیکون مستقل دارد و بدون اینترنت هم باز می‌شود.

**کاملاً آفلاین بدون نصب:** فایل `offline/watermark.html` را دانلود کن و با دوبار کلیک باز کن. تک‌فایل است و به هیچ چیز وصل نمی‌شود.

## امکانات

- واترمارک **لوگو** یا **متن** (فونت، رنگ، دور خط، سایه، پلاک پشت متن)
- **لیست لوگوها** — لوگوهایت در مرورگر ذخیره می‌شوند و هر بار با یک کلیک انتخاب می‌شوند
- **رنگ‌آمیزی لوگو** — شکل لوگو حفظ می‌شود و فقط رنگش عوض می‌شود
- **۲۸ قالب آماده‌ی قرارگیری** با پیش‌نمایش زنده، برای نسبت‌های ۱:۱، ۴:۵، ۹:۱۶، ۱۶:۹، ۳:۲ و ۴:۳
- **جایگاه نسبی** — ۹ نقطه‌ی آماده یا کشیدن آزاد؛ روی عکس عمودی و افقی یک‌جور می‌افتد
- **تکرار شطرنجی ضدکراپ** با فاصله، زاویه و چیدمان آجری
- **حالت‌های ترکیب رنگ** (multiply، screen، overlay، soft-light، …)
- **پیش‌نمایش مثل فتوشاپ** — زوم با Ctrl+اسکرول، حرکت با اسکرول و Shift+اسکرول، ابزار دست با Space
- **خروجی** JPG / PNG / WebP با کیفیت و تغییر اندازه، پیشوند و پسوند نام، دانلود تکی یا ZIP
- قالب‌های شخصی، تم روشن/تاریک، رابط کامل فارسی و راست‌چین

## انتشار روی Cloudflare

سه راه، از ساده به حرفه‌ای:

**۱. بدون نصب هیچ چیز (آپلود مستقیم)**
داشبورد Cloudflare ← Workers & Pages ← Create ← Pages ← *Upload assets* ← پوشه‌ی پروژه را بکش و رها کن.
آدرس: `https://watermark.pages.dev`

**۲. با یک دستور**
```bash
npx wrangler login
npx wrangler deploy
```
تنظیماتش در `wrangler.jsonc` آماده است. آدرس: `https://watermark.<اکانت>.workers.dev`

**۳. انتشار خودکار با هر push**
در تنظیمات ریپو این‌ها را بساز و تمام — هر بار که چیزی عوض شد، خودش منتشر می‌شود:
- Secrets: `CLOUDFLARE_API_TOKEN` (با دسترسی Workers Scripts: Edit) و `CLOUDFLARE_ACCOUNT_ID`
- Variables: `DEPLOY_CLOUDFLARE` = `true`

## اجرای محلی

```bash
python3 -m http.server 8080
# بعد: http://localhost:8080
```

برای سرویس‌ورکر و نصب، لازم است از `http://localhost` یا `https` باز شود؛ باز کردن مستقیم `index.html` با فایل، نسخه‌ی بدون نصب را می‌دهد (برای آن از `offline/watermark.html` استفاده کن).
